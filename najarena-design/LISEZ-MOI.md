# Najarena — pack design pour Claude Code

## Contenu
- `design-system/najarena/MASTER.md` : règles de design globales (source de vérité).
- `design-system/najarena/pages/` : règles propres à l'accueil, au profil et à la page tournoi.
- `public/brand/` : logo (version provisoire vectorisée).
- `public/avatars/` : 5 avatars gratuits (01–05) et 3 premium (p1–p3).
- `maquettes/` : code source des maquettes, à utiliser comme RÉFÉRENCE (mise en page, textes, tailles, couleurs).
  Ce ne sont pas des pages prêtes à l'emploi : elles utilisent un format de maquette spécifique
  (balises `sc-for`, `sc-if`, `{{variables}}`, données dans `renderVals()`).
